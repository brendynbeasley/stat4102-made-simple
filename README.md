# STAT 4102 Made Simple

A plain-English study guide for a mathematical statistics course: sixty-two short lessons, each with the idea, a recipe, one worked example and practice with answers. Lessons 1–37 follow the course (Wackerly Chapters 7–11). Lessons 38–62 finish the textbook (Chapters 12–16: experimental design, analysis of variance, chi-square tests, rank tests and Bayesian methods). It also has a symbol decoder, flashcards, one-page review sheets, a "Which test do I use?" chart, and tables for t, chi-square and F.

**Open the guide:** https://brendynbeasley.github.io/stat4102-made-simple/
