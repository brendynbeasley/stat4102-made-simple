# STAT 4102 Made Simple

A plain-English study guide for a mathematical statistics course: twenty short lessons, each with the idea, a recipe, one worked example and practice with answers. It also has a symbol decoder, flashcards and a one-page review sheet.

**Open the guide:** https://brendynbeasley.github.io/stat4102-made-simple/

## What is here

| File | What it is |
|---|---|
| `index.html` | The whole guide in one page. Equations are pre-rendered, so it needs no math library. |
| `STAT4102-Exam-II-flashcards.apkg` | The 37 flashcards as an Anki deck. In Anki choose File → Import. |

This folder is generated. Edit the lesson text in the guide's source and rebuild rather than editing `index.html` by hand.
